# 🐾 Cat Maze Runner

A Python-based maze game built using Tkinter and PIL.

## Features

* Multi-level maze with increasing difficulty
* Player animation using sprite frames
* Moving obstacles with collision detection
* Timer and life system

## Tech Stack

* Python
* Tkinter
* PIL (Pillow)

## How to Run

1. Install dependencies:
   pip install pillow

2. Run the game:
   python main.py

## About

This project was built to explore game logic, UI design, and real-time interaction using Python.
